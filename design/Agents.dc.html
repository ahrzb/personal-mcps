Board notes
• Every column reads from tools that exist: agent_list (grants with modes), token_list, connection_list, approval_list, audit_query { principal }.
• A plain list, one row per agent, no expansion: the Access column is one line of totals (which apps, what is reached, how much needs approval, how much is dormant) and the slug leads to the three-pane agent page, which is where every per-app detail and every edit lives (AgentThreePane).
• The row is the link. The slug is an anchor stretched over the whole row (a ::after covering it, no script), so any click on the row opens the agent page; the row highlights on hover, the cursor is a pointer, and a chevron at the row’s end says where it goes. Delete sits above the stretched link, so it still deletes. The claude row is drawn in its hover state.
• Row actions are Delete alone. Granting lives on the agent page: the rail’s “Grant another app…” and the listing pane.
• The row counts dormant entries (archived app, undeclared role, item matching nothing today); the agent page shows which.
