Board notes
• Three readings of one filtered set. Summary answers “is anything wrong?”, Sessions reads a client’s visit end to end, Events is the log itself (AuditViews). The window, the facets and the search are one state in the URL — view, since/until, repeated principal / app / event / tool / outcome / session, q, expand, open — so every state here is a link.
• The workspace shape (layout & density ladder §2): full width inside 24 px gutters, the facet rail 200 px as its own card, 12 px between cards. Rows are dense (32 px, 6 / 16), controls 32 / 24, badges and chips 20 / 11, nothing below 11 px. Audit moves out of the table row of the shape table into the workspace row.
• The lane strip is the window control. One lane per principal (at most six, busiest first, the rest folded into “N others” whose name carries them on hover), one cell per hour of the retention window, each cell the worst outcome in that hour under the current facets and search. Drag selects; 1h · 24h · 7d sit beside the title (the last labelled from retentionDays, so the label never names a week the deployment may not keep) and Whole window clears. The strip is focusable: ←/→ move the brush by an hour, Shift+←/→ resize it.
• Colour never carries an outcome alone. Five classes — ok, approval (−32003), archived (−32002), denied (−32001, −32000), error — and the class NAME is printed beside every swatch, chip and legend entry, with the raw codes after it where they differ.
• Facets count exhaustively (Hearst): a value’s count is taken under every other filter but its own group’s, so a group never collapses to one row as you click. Several values in one group OR, groups AND, top 5 (6 for tool and event) with Show all N expanding in place. session is never listed — it is set from a record.
• Worth a look is three hand-written rules, each with show me: the worst refused (principal, target) pair past 5, tools first called in the last two days, and changes to the setup (admin.*, upstream.*). With no reason in the ledger the first sentence ends at the outcome class — “refused 230 times calling news/search_news — denied.”
• Export JSONL is a plain link to /audit/export.jsonl carrying the current selection — the same read serialized, never a second one. An outcome class is the page’s own grouping, so the link expands it to the raw codes the column holds; the tool facet is a pair, so it travels whole as target=<app>/<tool> rather than as app= + tool=, which would export their cross product.
• One query per window. Facets, lanes, merging and sessions are computed client-side over the loaded rows, so a facet click never fetches and dragging the brush never fetches. Over the ceiling (AUDIT_EXPLORER_ROWS = 5,000) the page says so and the hours it could not load draw hatched, never empty (AuditDetailStates).
