Common to every option
• The row summary is settled: past three apps it says "20 apps · 1 archived" and keeps the totals line. Every list option above shares it.
• One order everywhere: dormant first, then apps with approval entries, then the rest by last call. Whatever the list shows is a prefix of what the page shows.
• Dormant rows are dimmed, not removed: the grant exists and Edit still works.
• The pair editor is untouched: it is per app, and twenty apps is twenty editors, each the size it is today.
• Reads: one agent_list, one app_list, and the catalog per app the reach needs — the page reads it anyway; the list expansion reads it only for the rows it draws, which is the quiet argument for A, C and D over B.
