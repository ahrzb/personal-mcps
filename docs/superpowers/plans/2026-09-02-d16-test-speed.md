`AGGREGATED_LIST_DEADLINE_MS → 150`: the ratio the two-knob row (`:1337-1349`) needs

order of magnitude, and a `hang` row now costs 0.3 s instead of 30. ONE mechanism covers

## Shape

One workflow, sequential by construction — the causes touch disjoint files, but every
measurement needs the machine to itself, so nothing runs concurrently with a timing run:

1. **cause-1 agent** — `harness/timers.ts`, `upstream-proxy.test.ts`, migrate
   `listen.test.ts` and `stream.test.ts`; run the three files; full run, timed.
2. **cause-2 agent** — one line; run `protocol.test.ts`; full run, timed.
3. **cause-3 agent** — the config block ×2; cold-cache measurement; run the worker
   project; full run, timed.
4. **cause-4 agent** — the describe restructure; run `web-pages.test.ts`, then with
   `--sequence.shuffle`; the inventory regeneration, timed; `git diff --exit-code
   test-inventory.json`.
5. **reviewer** — the DoD read off the diff: empty production diff, the never-faked list,
   the two-knob assertions and `CASE_BUDGET_MS` derivation, PSD over the four diffs; the
   per-file thresholds off the final JSON.

Agents do not commit. The four commits are made afterwards from the final tree,
file-scoped (each cause owns disjoint files), in the report's order, so each intermediate
commit is base + one cause and green alone. All agents Opus.
